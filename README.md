# Confidence-Gated Recovery

**Recalling evicted tokens in compressed KV caches for long-context LLM inference**

Decoder-only language models keep a key-value (KV) cache of every past token, and for long prompts this cache dominates GPU memory. Eviction methods such as SnapKV shrink it by scoring the context tokens from the attention of the last 32 prompt tokens and deleting all but the top few percent, but the deletion is final: a token that generation needs later cannot be brought back. Confidence-Gated Recovery (CGR) is a training-free extension of SnapKV that removes this limit. The evicted keys and values are kept in CPU memory, and the maximum next-token probability is monitored during greedy decoding. When it falls below a threshold (0.7), the backed-up tokens are re-scored by the attention the current query would give them, the stored score of each token becomes the maximum of its old and new score, the top-B tokens are selected again, the GPU cache is rebuilt from the backup and the same step is decoded again. Cached keys already carry their rotary position encoding, so tokens can be swapped without touching positions, and the number of cache slots on the GPU never changes.

The method is evaluated with Qwen2.5-1.5B-Instruct (float32, one T4 GPU) on three LongBench question-answering sets (HotpotQA, 2WikiMultihopQA, Qasper) and a synthetic two-needle retrieval test, 30 examples each, against Random, StreamingLLM, H2O and SnapKV re-implemented in one code path that shares a single uncompressed prefill per example. With 2% of the context kept, CGR raises the average score of SnapKV from 23.8 to 50.5 (full cache: 52.8) while recovering on about 13% of decoding steps; it is statistically indistinguishable from recovering on every step and clearly better than recovering at random steps, which shows that confidence is a useful trigger. The GPU cache falls from 302.5 MB to 7.8 MB, at the cost of a 300.8 MB CPU backup and about 137 ms per recovery. The gain is concentrated on retrieval-style failures at aggressive budgets and is absent on question answering at a 10% budget. The repository contains the method and baselines (`tamc/cgr.py`), the correctness tests, the Colab notebook, the analysis scripts and the raw results (`results/final`).
